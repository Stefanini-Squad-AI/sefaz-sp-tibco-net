ePAT — POC_EpatProcess: Estrutura do Fluxo Principal

Documento de validação para desenvolvedores do cliente. Descreve as etapas, subprocessos, decisões e cenários do fluxo migrado de TIBCO iProcess para .NET/Elsa.

T
Tarefa (user/service/send)
G
Gateway (decisão/convergência)
E
Evento (start/end/timer/signal)
S
Subprocesso (callActivity)
L
Link (goto entre raias)
1
Início — Iniciar Novo Graft

O AFR inicia o processo para um AIIM já existente. O motor cria a instância e suspende no primeiro evento externo.

○ Start Event ✉ Iniciar Novo Graft (receiveTask)
2
Preparação — Set Nome Etapa + Preparar Notificação

Após o sinal, configura a etapa 2, define destinatários, dispara e-mails e avalia se é necessário corrigir.

⚙ Set Nome Etapa 2 👤 Preparar Notificação (userTask) ⏰ Prazo Maximo Mantendo Atividade (non-interrupting boundary) ✉ Email Limite Rel 1 ⚙ Define Destinatários ✉ Email CQ Fechamento
Gateway: Corrigir?
◇ Corrigir? = Sim → continua ao Finalizar AIIM ◇ Corrigir? = Não → Criar Notificação (SC-015, encerra)
3
Finalizar AIIM + DEAT0050

Fecha o AIIM e inicia o subprocesso DEAT0050 (notificação). Inclui AND-split (execução paralela), graft-step e timer Aguarda Defesa.

👤 Finalizar AIIM (userTask) ⊕ AND-split (paralelo) ◇ Existe Notificação? ↗ Inicia Graft Step (link throw/catch) ⚙ Flag Retirati True GS ▣ Aguardar evento de Notificação do AIIM → DEAT0050
Gateway: Existe Notificação? = Sim
◇ SC-014: short-circuit → endEvent (10 nós)
Subprocesso DEAT0050 (inline)
✉ INICALC (evento externo) ⚙ CalculaPrazo + HoraFimSC ◇ Deve Aguardar Defesa? ⏰ Timer Aguarda Defesa (expression deadline: DATE+TIME) ⚙ Controlar Data
Modo Graft-Real (alternativo)
Filhos DEAT0050 anexam-se ao pai (graft-step) Pai prossegue quando janela fecha + todos os filhos terminaram
4
Decisões + PRPINTPC

Troca notificação, avalia regras Decisions (motor Corticon), prepara intimação via subprocesso PRPINTPC. Inclui retry/operador.

◇ Trocar Notificação? ↗ Iniciar Decisions (link throw/catch) ⚙ Verificar Anulação ▣ Prepara Intimação → PRPINTPC ⚙ Verificar Retorno Decisions (Corticon fold: 49 regras) ⚙ Define Destinatários ✉ Email Limite Rel 1
PRPINTPC falha (STATUS_CODE ≠ 0)
⚙ Retry loop (MAXRETRIES × NUMAPPRETRIES) 👤 Manipular Exceção (operador decide: R=retry, outro=abortar)
5
Verificar Retorno — 3 Vias (TIPOVISTAS)

Validação paralela dos resultados, depois gateway de 3 vias com base em TIPOVISTAS.

👤 Verificar Retorno Decisions (userTask) ↗ Validar Paralelos (link throw/catch) ◇ Vistas do Juiz? ◇ Tipo de Vista Mista?
Via JUIZ (SC-001, 30 nós)
👤 Vistas do Juiz (receiveTask — evento externo) ◇ Convergência
Via MISTA (SC-012, 29 nós)
⚙ VistaAgenda ⊙ Fim Vista Mista 👤 Realizar Atividade Vista Mista (receiveTask) ⚠ Catch Signal Event (Sim → encerra)
Via DRF (SC-010, 30 nós)
✉ Pedido de Vistas (receiveTask — corrida contra timer) ⏰ Timer PRAZORETRA (expression deadline — vence → Fim de Prazo) ⚙ Busca Envolvidos → BSCENVPC
6
Convergência + prepSub → Controlar Intimados

As 3 vias convergem. O fluxo prepara o subprocesso dinâmico e invoca CONTROPC. A instância encerra.

⊕ Convergência (AND-join das vias) ◇ caso contrário / No ⚙ prepSub (resolução dinâmica) ▣ Controlar Intimados → CONTROPC (dynamic subprocess via AGUARDAR registry) ⊙ Fim (endEvent)

Conceitos BPM Demonstrados

Modelagem BPMN
XOR, AND, start/end — todo o fluxo
Subprocessos Encadeados
DEAT0050, PRPINTPC, CONTROPC, CRNOTPC
Subprocesso Dinâmico
CONTROPC via AGUARDAR registry
Graft Step
Filhos DEAT0050 anexam ao pai (etapa 3)
Evento Externo
INICALC, Iniciar Novo Graft, Vistas do Juiz
Expression Deadline
DATE(PRAZODEFESA)+TIME — timer absoluto
Non-Interrupting Boundary
Prazo Máximo Mantendo Atividade (etapa 2)
Link/Goto
Corrigir Fechamento, Iniciar Decisions, Validar Paralelos
Correlação Assíncrona
Bookmark + CorrelationId por PROCESS_ID
Regras Decisions (Corticon)
49 regras, fold override, nó 18
Retry + Operador
PRPINTPC: MAXRETRIES → Manipular Exceção
Persistência Durável
SQLite — instância sobrevive restart
Execução Paralela
AND-split/join (etapas 3 e 5)
Notificação (E-mail)
Email Limite Rel 1, Email CQ Fechamento
Compatibilidade iProcess
SW_NA tri-state, SW_CASENUM, CALCTIME
