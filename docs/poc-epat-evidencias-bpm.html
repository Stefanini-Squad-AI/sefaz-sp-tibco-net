2User Tasks PROVEN

Tarefas humanas suspendem a instância via bookmarks duráveis (SQLite). A suspensão sobrevive o reinício do host.

Código — Criação de bookmark (suspensão)

private void Suspend(ActivityExecutionContext context, PocEpatMainSnapshot snap,
    string bookmark, ExecuteActivityDelegate callback)
{
    context.GetRequiredService<PocEpatProcessState>().Save(snap.ProcessId, snap);
    var pid = context.WorkflowExecutionContext.CorrelationId ?? "";
    context.CreateBookmark(new CreateBookmarkArgs
    {
        BookmarkName = bookmark,
        Stimulus = new PocEpatStimulus(pid),
        Callback = callback,
        IncludeActivityInstanceId = false,
    });
}

public static bool Evaluate(AiimCase aiimCase)
{
    // SW_NA é terceiro estado distinto de null/vazio (hipótese 3)
    return aiimCase.TIPOVISTAS.Match(
        hasValue:     v => string.Equals(v, "JUIZ", StringComparison.Ordinal),
        notAvailable: () => true,    // SW_NA → caminho juiz
        empty:        () => false);
}

Decisions / Motor de Regras (Etapa 3 do documento)

Código — Corticon override fold (49 regras)

public IntimacoesResponse Evaluate(IntimacoesRequest request)
{
    var response = new Dictionary<string, string?>();
    // Override fold: todas as regras que casam disparam; última escrita ganha
    foreach (var rule in _rules)
    {
        if (rule.Conditions.All(c => Matches(c, request)))
            foreach (var action in rule.Actions)
                response[action.Attribute] = action.Value;
    }
    return new IntimacoesResponse(response);
}
